# Gaming & Tech Store

## About the Project
This is a practice website I'm building to improve my web development skills using Eleventy, Nunjucks and Bulma.

The website has four pages: Home, Products, About and Contact.

## Technologies Used
- HTML
- CSS
- Eleventy
- Nunjucks
- Bulma
- Git and GitHub

## Getting Started
Install dependencies:

```bash
npm install
```

Run the website:

```bash
npx @11ty/eleventy --serve
```

Open http://localhost:8080/ in your browser.
